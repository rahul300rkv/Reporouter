About Repo Router

Repo Router is a small, free tool that saves developers a repetitive step: turning a GitHub repository link into the address a different AI-oriented tool expects.

Why it exists

Tools such as GitMCP, DeepWiki, Gitingest and UIthub each use a slightly different version of the GitHub URL. Editing addresses by hand is easy to get wrong and tedious when you try several repositories in a row. Repo Router does the conversion, shows you the result before you leave the page, and keeps the original repository in one place while you switch destinations.

What you can do with it

  • Convert a repository link for GitMCP, DeepWiki, Gitingest or UIthub.
  • Preview the transformation, copy the link, share it or turn it into a QR code.
  • Generate a README badge that opens Repo Router with your repository filled in.

How it works

Everything happens in your browser. Repo Router rewrites the address locally and only contacts GitHub's public API to display basic repository details such as stars and language. It does not upload your code, require an account, or store your repository list on a server. Details are in our privacy policy.

About the guides

The guide library grew out of questions people ask when they start using these tools: what MCP is, how to connect it to an editor, how to keep context small, and how to stay safe. We aim to write original, practical explanations and to say plainly when something may have changed. If you spot an error or out-of-date step, please tell us through the contact page and we will correct it.

Who builds it

Repo Router is an independent project created and maintained by a developer who wanted a faster way to move between these tools. It is not affiliated with GitHub, Anthropic, Cognition, GitMCP, Gitingest or UIthub. All product names belong to their respective owners.
