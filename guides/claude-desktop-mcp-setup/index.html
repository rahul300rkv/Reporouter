Claude Desktop Setup: Connect MCP Servers Step by Step

By the Repo Router team·Updated November 17, 2026·6 min read

Claude Desktop can connect to MCP servers so that Claude can read documentation or use tools during a conversation. The classic method is a JSON config file, which this guide walks through.

NoteAnthropic has also been adding a built-in way to add remote servers through the app's connector settings on some plans. If you see that option in Settings, it can be simpler than editing a file. Check Anthropic's help pages for current availability.

Before you start

  • Install the Claude Desktop app and sign in.
  • Install Node.js if you plan to use the npx method below. Run node --version in a terminal to confirm.
  • Get your server URL from Repo Router, for example https://gitmcp.io/owner/repo.

Step 1: open the config file

In the app, open Settings, go to the Developer section and choose the option to edit the config. This opens the folder containing claude_desktop_config.json. By default it lives here:

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json

Step 2: add a server

Because the config file launches local processes, remote servers are connected through the mcp-remote bridge:

{
  "mcpServers": {
    "project-docs": {
      "command": "npx",
      "args": ["mcp-remote", "https://gitmcp.io/owner/repo"]
    }
  }
}

If the file already has other servers, add your entry inside the existing mcpServers object and separate entries with commas.

Step 3: restart completely

Quit Claude Desktop fully, not just close the window, then open it again. The app reads the file at startup.

Step 4: check that it works

  1. Start a new chat and look for the tools or connector indicator near the message box.
  2. Open it and confirm your server and its tools appear.
  3. Ask a question that needs the documentation, naming the server: "Using project-docs, explain how configuration files are loaded."
  4. Approve the tool call if the app asks for permission.

Troubleshooting

  • Nothing appears: validate the JSON. Trailing commas and smart quotes are the usual culprits.
  • "npx not found": install Node.js, then restart the app so it picks up the updated path.
  • Server starts then drops: check the app's log files, which are typically in a Logs/Claude folder on macOS and a logs folder next to the config on Windows.
  • Claude does not use the tool: mention the server by name, and make sure it is enabled for the chat.

Permissions

Claude asks before running most tool calls. Read the request before you approve it, and prefer read-only servers for documentation lookups. The security checklist explains what to look for.
